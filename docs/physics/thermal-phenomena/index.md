# 热现象

热现象是生活中最常见的物理现象之一。从一杯热水的慢慢变凉，到夏天湿衣服被晒干，再到冬天窗玻璃上结出的冰花——这些都与温度及物态变化有关。

:::

物质从液态变成气态叫**汽化**（蒸发和沸腾），从气态变成液态叫**液化**。汽化吸热，液化放热。
:::

## 温度及其测量

### 温度

温度 (temperature) 是表示物体**冷热程度**的物理量。

**摄氏温度**（Celsius）曾经是这样规定的：
- 在标准大气压下，**冰水混合物**的温度定为 **0℃**
- **沸水**的温度定为 **100℃**
- 0℃ 和 100℃ 之间分成 100 等份，每一等份是 **1℃**

### 温度计

常用温度计的工作原理是**液体的热胀冷缩**（如酒精温度计、水银温度计）。

正确使用温度计要做到「**放、看、读、记**」：

1. **放**：温度计的玻璃泡全部浸入被测液体中，不要碰到容器底或容器壁
2. **看**：待示数稳定后再读数，视线要与温度计中液柱的液面相平
3. **读**：读数时温度计的玻璃泡要继续留在液体中，不能取出来读数
4. **记**：记录结果包括数值和单位

### 体温计

体温计是一种专门用于测量人体温度的温度计。

| 项目 | 参数 |
| :--- | :--- |
| 量程 | 35℃ ~ 42℃ |
| 分度值 | 0.1℃ |

::: card title="体温计的特殊结构——缩口"
体温计的玻璃泡和直玻璃管之间有**缩口**（缩口设计），使得体温计离开人体后，直管内的水银不能自动退回玻璃泡，因此体温计**可以离开人体读数**。使用前要将体温计用力向下**甩几下**（其他温度计不能甩）。
:::

## 熔化和凝固

### 物态变化

固态、液态和气态是物质常见的三种状态。随着温度的变化，物质会在固、液、气三种状态之间变化。物质各种状态间的变化叫作物态变化。

### 熔化和凝固

- **熔化** (melting)：物质从**固态**变成**液态**的过程（如冰变成水）
- **凝固** (solidification/freezing)：物质从**液态**变成**固态**的过程（如水变成冰）

### 晶体和非晶体

固体分为**晶体** (crystal) 和**非晶体** (amorphous solid) 两大类。

| 类别 | 晶体 | 非晶体 |
| :--- | :--- | :--- |
| 定义 | 有固定熔化温度的固体 | 没有固定熔化温度的固体 |
| 常见物质 | 冰、海波、各种金属 | 蜡、玻璃、沥青、松香 |
| 熔化过程 | 温度保持不变（有熔点） | 温度持续升高（无熔点） |
| 凝固过程 | 温度保持不变（有凝固点） | 温度持续降低（无凝固点） |

**熔点和凝固点**
- 晶体熔化时的温度叫作**熔点** (melting point)
- 液体凝固形成晶体时的温度叫作**凝固点** (solidifying point/freezing point)

::: tip 晶体熔化条件
🎯 晶体熔化的两个条件**缺一不可**：
1. 温度**达到熔点**
2. 能**继续吸热**

例如：冰水混合物在 0℃ 时，如果不继续吸热（如从外界加热），冰就不会继续熔化。
:::

### 熔化吸热、凝固放热

- **熔化吸热**：晶体在熔化过程中吸收热量，但温度保持不变（这部分热量用于破坏晶体的分子排列）
- **凝固放热**：晶体在凝固过程中放出热量，但温度保持不变

::: info 应用
- 北方的冬天，在菜窖里放几桶水，利用水凝固时放出的热量防止菜被冻坏
- 夏天吃冰棍感觉凉爽，是因为冰熔化时从人体吸收了热量
:::

## 汽化和液化

### 汽化

物质从**液态**变成**气态**的过程叫做**汽化** (vaporization)。汽化有**蒸发** (evaporation) 和**沸腾** (boiling) 两种方式，汽化需要**吸热**。

#### 蒸发

蒸发是只在液体**表面**进行的汽化现象，可以在**任何温度**下发生。

**影响蒸发快慢的因素：**

1. **液体温度**越高，蒸发越快
2. **液体表面积**越大，蒸发越快
3. **液体表面空气流速**越大，蒸发越快

::: card title="蒸发吸热有制冷作用"
液体蒸发时要从周围环境中吸收热量，使液体和周围环境的温度降低，因此蒸发有**制冷作用**。

例如：夏天在地面洒水感觉凉快；游泳上岸后感觉冷；酒精擦在皮肤上感觉凉快。
:::

#### 沸腾

沸腾是在液体**表面和内部同时**进行的剧烈汽化现象。

各种液体沸腾时都有确定的温度，这个温度叫作**沸点** (boiling point)。

::: tip 沸腾条件
🎯 液体沸腾的两个条件**缺一不可**：
1. 温度**达到沸点**
2. 能**继续吸热**
:::

**沸点与气压的关系：**

- 气压**越高**，沸点**越高**
- 气压**越低**，沸点**越低**

> 例如：高山上煮饭不易煮熟，因为气压低、沸点低；高压锅利用增大气压来提高沸点，使食物更快煮熟。

#### 蒸发与沸腾的对比

| 比较 | 蒸发 | 沸腾 |
| :--- | :--- | :--- |
| 发生部位 | 液体表面 | 液体表面和内部同时 |
| 温度条件 | 在任何温度下均可 | 达到沸点 |
| 剧烈程度 | 缓慢 | 剧烈 |
| 影响因素 | 温度、表面积、空气流速 | 气压 |

### 液化

物质从**气态**变成**液态**的过程叫做**液化**。液化需要**放热**。

所有气体在温度降到足够低时都可以液化。

**液化的两种方法：**

1. **降低温度**（最常见的方法）
2. **压缩体积**（在一定温度下，压缩气体体积使其液化）

::: info 液化放热
气体液化时会放出大量的热。例如：被 100℃ 的水蒸气烫伤往往比被 100℃ 的水烫伤更严重，因为水蒸气液化时会放出大量的热。
:::

::: card title="生活中的液化现象"
- 冬天呼出的"白气"：呼出的水蒸气遇冷液化
- 夏天冰棍周围冒"白气"：空气中的水蒸气遇冷液化
- 烧水时壶嘴冒出的"白气"：水蒸气喷出后遇冷液化
- 露珠的形成：空气中的水蒸气遇冷液化
:::

## 升华和凝华

### 升华

物质从**固态**直接变成**气态**的过程叫做**升华** (sublimation)。升华需要**吸热**。

::: card title="升华的例子"
- **干冰（固态二氧化碳）升华**：干冰升华吸热，使周围温度急剧降低，用于人工降雨、制造舞台烟雾效果
- **碘升华**：固态碘加热后直接变成紫色的碘蒸气
- **樟脑丸变小**：樟脑丸（卫生球）在衣柜中逐渐变小
- **冰冻的衣服变干**：冬天冰冻的衣服未熔化却直接变干
:::

### 凝华

物质从**气态**直接变成**固态**的过程叫做**凝华** (deposition)。凝华需要**放热**。

::: card title="凝华的例子"
- **霜的形成**：空气中的水蒸气遇冷凝华成小冰晶附着在地面或植物上
- **冬天窗花**：室内温度较高的水蒸气遇到冰冷的玻璃窗，凝华成冰花
- **雾凇**：空气中的水蒸气遇冷凝华在树枝上形成的白色冰晶
- **碘蒸气的凝华**：紫色的碘蒸气遇冷直接变成固态碘
:::

### 物态变化中的吸放热规律

::: card
- **吸热**：熔化（固→液）、汽化（液→气）、升华（固→气）
- **放热**：凝固（液→固）、液化（气→液）、凝华（气→固）

记忆技巧：**"熔汽升"（熔汽升→融气升→熔化的需要吸收热量）**—— 三个吸热过程都是物质从"密集"状态变为"松散"状态的过程。
:::

## 速记

::: card

- **温度计使用**：放、看、读、记，体温计有缩口可离体读数。
- **晶体与非晶体**：晶体有固定的熔点/凝固点，非晶体没有。
- **晶体熔化条件**：达到熔点 + 继续吸热。
- **蒸发与沸腾**：蒸发在任何温度下进行（表面），沸腾在沸点进行（表面+内部）。
- **液化方法**：降温、压缩体积。
- **物态变化与吸放热**：
  - 吸热：熔化、汽化、升华（固→液→气）
  - 放热：凝固、液化、凝华（气→液→固）

:::
