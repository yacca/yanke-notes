# 凸透镜成像规律实验

凸透镜镜成像规律是初中物理光学部分的重点。通过调整物体到透镜的距离（物距 $u$），我们可以观察到像的大小、倒正和虚实的变化。

## 核心规律总结

根据实验观察，我们可以总结出以下五个关键节点：

1. **$u > 2f$**：得到**倒立、缩小、实像**。像在透镜另一侧，处于 $f$ 到 $2f$ 之间。
2. **$u = 2f$**：得到**倒立、等大、实像**。这是区分像放大或缩小的转折点。
3. **$f < u < 2f$**：得到**倒立、放大、实像**。像在 $2f$ 之外。
4. **$u = f$**：折射光线变为平行光，**不成像**。
5. **$u < f$**：得到**正立、放大、虚像**。像与物在透镜同侧。

> [!TIP] 技巧
>
> - **一倍焦距分虚实**：$u > f$ 成实像，$u < f$ 成虚像。
> - **二倍焦距分大小**：$u > 2f$ 成缩小像，$u < 2f$ 成放大像。
> - **实像倒立在异侧，虚像正立在同侧。**
