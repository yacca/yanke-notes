## 长度和时间的测量

### 长度的单位

国际单位制中，长度的基本单位是**米**（meter），符号是 $\text{m}$。

| 单位 | 符号 | 与米的换算关系 |
| :--- | :---: | :--- |
| 千米 | $\text{km}$ | $1\text{km}=10^3\text{m}$ |
| 分米 | $\text{dm}$ | $1\text{dm}=10^{-1}\text{m}$ |
| 厘米 | $\text{cm}$ | $1\text{cm}=10^{-2}\text{m}$ |
| 毫米 | $\text{mm}$ | $1\text{mm}=10^{-3}\text{m}$ |
| 微米 | $\mu\text{m}$ | $1\mu\text{m}=10^{-6}\text{m}$ |
| 纳米 | $\text{nm}$ | $1\text{nm}=10^{-9}\text{m}$ |

### 刻度尺的使用

<img src="./ruler.svg" width="100%" />

正确使用刻度尺要做到「**选、放、看、读、记**」：

1. **选**：根据测量需要选择合适的**量程**和**分度值**
2. **放**：刻度尺有刻度的一边紧贴被测物体，与所测长度平行，不能倾斜
3. **看**：读数时视线要与尺面垂直
4. **读**：要估读到**分度值的下一位**（估读）
5. **记**：测量结果由**准确值**、**估读值**和**单位**三部分组成

::: info 估读
估读是长度测量的关键——读数时，除了读出准确值，还要把测量结果**估读到分度值的下一位**。即使正好对齐，也要在末尾补一个"0"。

例如：分度值是 $1\text{mm}$ 的刻度尺，读数应为 $2.31\text{cm}$（$2.3\text{cm}$ 是准确值，$0.01\text{cm}$ 是估读值）。
:::

### 时间的测量

时间的基本单位是**秒**（second），符号 $\text{s}$。

| 单位 | 符号 | 换算关系 |
| :--- | :---: | :--- |
| 小时 | $\text{h}$ | $1\text{h}=60\text{min}=3.6\times 10^3\text{s}$ |
| 分钟 | $\text{min}$ | $1\text{min}=60\text{s}$ |
| 毫秒 | $\text{ms}$ | $1\text{ms}=10^{-3}\text{s}$ |
| 微秒 | $\mu\text{s}$ | $1\mu\text{s}=10^{-6}\text{s}$ |

**常用测量工具**：秒表（停表）、电子秒表、机械秒表。

::: info 秒表读数方法
机械秒表有两个表盘：
- **大表盘**：通常为秒针，每圈 $30\text{s}$ 或 $60\text{s}$
- **小表盘**：通常为分针，每圈 $15\text{min}$ 或 $30\text{min}$

读数时：**小表盘读出分钟数 + 大表盘读出秒数**。
:::

### 误差

**误差与错误的区别**
- **误差**：测量值与真实值之间的差异。**不可避免**，只能减小。
- **错误**：测量方法不正确或操作不规范造成的。**可以避免**。

**减小误差的方法**：
1. 选用更精密的测量工具
2. 改进测量方法
3. 多次测量取平均值

## 运动的描述

### 机械运动

::: info 机械运动
在物理学中，物体**位置随时间的变化**叫作**机械运动**（mechanical motion）。
:::

机械运动是宇宙中最普遍的运动形式。

### 参照物

要描述一个物体是运动还是静止，需要先选定一个物体作为**标准**。这个作为标准的物体叫作**参照物**（reference object）。

::: card
- 参照物**可以任意选择**，但一般选择对地面静止的物体
- 研究地面上物体的运动时，常选**地面或固定在地面上的物体**作为参照物
- 参照物一旦选定，就**假定它是不动的**
:::

### 运动和静止的相对性

同一个物体是运动还是静止，取决于所选的**参照物**——这就是运动和静止的**相对性**。

::: card title="典型例子"
- **乘客与路标**：坐在行驶汽车中的乘客，以路边的树为参照物是运动的，以汽车为参照物是静止的
- **同步卫星**：以地球为参照物是静止的，以太阳为参照物是运动的
- **接力赛交接棒**：交接棒时，两位运动员保持相对静止，交接最顺利
- **空中加油**：加油机与受油机保持相对静止，才能安全对接
:::

## 运动的快慢

### 速度

速度是表示物体运动**快慢**的物理量。

::: tip 速度的定义
🎯 在物理学中，把**路程与时间之比**叫作**速度**（velocity）。
:::

::: formula
$$
v = \frac{s}{t}
$$

- $v$：速度
- $s$：路程
- $t$：时间
:::

**单位**：
- 国际单位：米每秒，符号 $\text{m/s}$
- 常用单位：千米每小时，符号 $\text{km/h}$
- 换算关系：$1\text{m/s}=3.6\text{km/h}$

::: info 单位换算技巧
$$
1\text{m/s} = \cfrac{1\text{m}}{1\text{s}} = \cfrac{\cfrac{1}{1000}\text{km}}{\cfrac{1}{3600}\text{h}} = 3.6\text{km/h}
$$

$\text{m/s}$ 到 $\text{km/h}$ 乘以 $3.6$，$\text{km/h}$ 到 $\text{m/s}$ 除以 $3.6$。
:::

### 匀速直线运动

匀速直线运动是最简单的机械运动

::: info 定义
物体沿着**直线**且速度**大小保持不变**的运动，叫作**匀速直线运动**（uniform rectilinear motion）。
:::

**特征**：在任何相等的时间内，通过的路程都相等。

### 变速运动与平均速度

物体在运动过程中，速度常常是变化的。这种运动叫作**变速运动**。

::: formula
$$
\bar{v} = \frac{s_\text{总}}{t_\text{总}}
$$

$\bar{v}$ 表示**平均速度**，用来粗略描述物体在某一段路程或某一段时间内的运动快慢。
:::

::: card title="平均速度≠速度的平均值"
平均速度是总路程除以总时间，**不是**各段速度的算术平均值。

例如：去程速度 $v_1$，回程速度 $v_2$，全程的平均速度是 $\cfrac{2v_1v_2}{v_1+v_2}$，而不是 $\cfrac{v_1+v_2}{2}$。
:::

## 实验：测量平均速度

::: info 实验原理
利用 $v = \cfrac{s}{t}$，测量小车在斜面上通过的路程 $s$ 和所用时间 $t$，计算出小车的平均速度。
:::

**实验器材**：斜面、小车、刻度尺、秒表、金属片

**实验步骤**：
1. 将斜面一端垫高，保持较小的坡度
2. 将金属片固定在斜面底端，用刻度尺测出小车将要通过的路程 $s_1$
3. 用秒表测量小车从斜面顶端由静止滑下到撞击金属片的时间 $t_1$
4. 利用公式 $v_1 = s_1/t_1$ 计算出小车通过全程的平均速度
5. 将金属片移至斜面中部，重复上述步骤，测出小车通过上半段的平均速度 $v_2$

::: card title="实验注意事项"
- 斜面坡度**不宜过大**（方便计时），也**不宜过小**（小车可能不动）
- 测量时间时，**多次测量取平均值**以减小误差
- 小车从**静止释放**，每次从**同一位置**释放
- 金属片的作用：便于准确测量时间（听到撞击声时停止计时）
:::

## 速记

::: card

- **刻度尺口诀**：选放看读记，估读到下一位。
- **误差与错误**：误差不可避免（可减小），错误可以避免。
- **参照物**：判定动与静，先要选标准。
- **速度公式**：$v = \cfrac{s}{t}$，单位换算 $\times 3.6$。
- **匀速直线运动**：直线、速度不变。
- **平均速度**：总路程 ÷ 总时间，不是速度的平均。
- **$s$-$t$ 图**：斜线匀速，水平静止，越陡越快。

:::
