# 初中物理公式汇总

中考复习必备，按知识板块分类整理。

## 力学

### 运动

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 速度 | $v = \dfrac{s}{t}$ | $v$ — 速度 (m/s)<br>$s$ — 路程 (m)<br>$t$ — 时间 (s) | 1 m/s = 3.6 km/h |
| 平均速度 | $\bar{v} = \dfrac{s_{\text{总}}}{t_{\text{总}}}$ | | 不是速度的平均值 |

::: info 单位换算
$1\ \text{m/s} = 3.6\ \text{km/h}$，$1\ \text{km/h} = \dfrac{1}{3.6}\ \text{m/s}$
:::

### 密度

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 密度 | $\rho = \dfrac{m}{V}$ | $\rho$ — 密度 (kg/m³)<br>$m$ — 质量 (kg)<br>$V$ — 体积 (m³) | 密度是物质特性 |
| 质量 | $m = \rho V$ | | 质量不随位置、形状、状态改变 |
| 体积 | $V = \dfrac{m}{\rho}$ | | |

::: info 单位换算
$1\ \text{g/cm}^3 = 1\times 10^3\ \text{kg/m}^3$
:::

### 重力

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 重力 | $G = mg$ | $G$ — 重力 (N)<br>$m$ — 质量 (kg)<br>$g$ — 重力常数 (N/kg) | $g \approx 9.8\ \text{N/kg}$ |

### 压强

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 压强（定义式） | $p = \dfrac{F}{S}$ | $p$ — 压强 (Pa)<br>$F$ — 压力 (N)<br>$S$ — 受力面积 (m²) | 适用于固体、液体、气体 |
| 液体压强 | $p = \rho gh$ | $\rho$ — 液体密度 (kg/m³)<br>$h$ — 深度 (m) | 液体压强与方向无关 |

### 浮力

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 阿基米德原理 | $F_{\text{浮}} = G_{\text{排}} = \rho_{\text{液}} g V_{\text{排}}$ | $V_{\text{排}}$ — 排开液体体积 (m³) | 与物体形状、密度无关 |
| 称重法 | $F_{\text{浮}} = G - F_{\text{示}}$ | $F_{\text{示}}$ — 弹簧测力计示数 (N) | 适用于可下沉物体 |
| 压力差法 | $F_{\text{浮}} = F_{\text{向上}} - F_{\text{向下}}$ | | 浮力产生原因 |
| 平衡法（漂浮/悬浮） | $F_{\text{浮}} = G$ | | 物体静止在液面上或悬浮 |

### 功和机械能

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 功 | $W = Fs$ | $W$ — 功 (J)<br>$F$ — 力 (N)<br>$s$ — 距离 (m) | 力与距离方向相同 |
| 功率 | $P = \dfrac{W}{t}$ | $P$ — 功率 (W)<br>$t$ — 时间 (s) | 表示做功快慢 |
| 功率（变形式） | $P = Fv$ | $v$ — 速度 (m/s) | 用于匀速运动 |

### 简单机械

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 杠杆平衡 | $F_1 L_1 = F_2 L_2$ | $L$ — 力臂 (m) | 动力×动力臂 = 阻力×阻力臂 |
| 滑轮组 | $F = \dfrac{G}{n}$ | $n$ — 承重绳子段数 | 不计摩擦和动滑轮重 |
| 滑轮组 | $F = \dfrac{G + G_{\text{动}}}{n}$ | $G_{\text{动}}$ — 动滑轮重 (N) | 考虑动滑轮重 |
| 机械效率 | $\eta = \dfrac{W_{\text{有用}}}{W_{\text{总}}} \times 100\%$ | $\eta$ — 机械效率 | $\eta < 100\%$ 恒成立 |

## 电学

### 欧姆定律

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 欧姆定律 | $I = \dfrac{U}{R}$ | $U$ — 电压 (V)<br>$R$ — 电阻 (Ω) | 同体性、同时性 |
| 电阻定义式 | $R = \dfrac{U}{I}$ | | 计算式，不是决定式 |

### 串并联电路规律

| 连接方式 | 电流 | 电压 | 电阻 | 分压/分流 |
|---------|------|------|------|-----------|
| **串联** | $I = I_1 = I_2$ | $U = U_1 + U_2$ | $R = R_1 + R_2$ | $\dfrac{U_1}{U_2} = \dfrac{R_1}{R_2}$ |
| **并联** | $I = I_1 + I_2$ | $U = U_1 = U_2$ | $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ | $\dfrac{I_1}{I_2} = \dfrac{R_2}{R_1}$ |

### 电功和电功率

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 电功 | $W = UIt$ | $W$ — 电功 (J)<br>$U$ — 电压 (V)<br>$I$ — 电流 (A)<br>$t$ — 时间 (s) | $1\ \text{kW·h} = 3.6\times 10^6\ \text{J}$ |
| 电功率 | $P = \dfrac{W}{t} = UI$ | $P$ — 电功率 (W) | |
| 电功率（变形式） | $P = I^2R = \dfrac{U^2}{R}$ | | 仅适用于纯电阻电路 |
| 焦耳定律 | $Q = I^2Rt$ | $Q$ — 热量 (J) | 适用于任何用电器 |

## 热学

| 物理量 | 公式 | 符号及单位 | 备注 |
|--------|------|-----------|------|
| 热量（比热容） | $Q = cm\Delta t$ | $c$ — 比热容 [J/(kg·°C)]<br>$m$ — 质量 (kg)<br>$\Delta t$ — 温度变化 (°C) | 吸热 $Q_{\text{吸}} = cm(t-t_0)$ |
| 热值 | $q = \dfrac{Q}{m}$ | $q$ — 热值 (J/kg)<br>$Q$ — 热量 (J)<br>$m$ — 质量 (kg) | 燃料完全燃烧放热 |
| 热机效率 | $\eta = \dfrac{W_{\text{有用}}}{Q_{\text{放}}} \times 100\%$ | $W_{\text{有用}}$ — 机械功 (J)<br>$Q_{\text{放}}$ — 燃料放热 (J) | |

## 物体和物质的固有属性

**物体的固有属性**

| 属性 | 物理意义 | 特点 |
|------|---------|------|
| **质量** ($m$) | 反映物体所含物质的多少及其惯性大小 | 不随位置、形状、状态和温度改变 |
| **惯性** | 反映改变物体运动状态的难易程度 | 只与质量有关，与速度无关 |
| **电阻** ($R$) | 反映导体对电流阻碍作用的大小 | 是导体本身的属性，通常与电压、电流无关 |

**物质的固有属性**

所有物质的固有属性与物质的多少没有关系。

| 属性 | 物理意义 | 特点 |
|------|---------|------|
| **密度** ($\rho$) | 反映物质在空间分布上的疏密程度 | 与质量和体积无关，受温度、状态影响 |
| **熔点与沸点** | 反映物质三态变化时的温度特性 | 同种物质熔点与沸点一般固定，受气压影响 |
| **比热容** ($c$) | 反映物质吸热或放热能力的强弱 | 与物质状态有关 |
| **热值** ($q$) | 反映燃料燃烧释放热量能力的大小 | 与燃烧是否充分无关 |


## 常用物理常数

| 常数名称 | 数值 | 说明 |
|---------|------|------|
| 真空中光速 | $c = 3.0 \times 10^8\ \text{m/s}$ | 真空中最快速度 |
| 空气中声速 | $v_{\text{声}} = 340\ \text{m/s}$ | 15°C，温度越高声速越大 |
| 标准大气压 | $p_0 = 1.013 \times 10^5\ \text{Pa}$ | 相当于 760 mm 汞柱 |
| 水的密度 | $\rho_{\text{水}} = 1.0 \times 10^3\ \text{kg/m}^3$ | 4°C 时密度最大 |
| 水的比热容 | $c_{\text{水}} = 4.2 \times 10^3\ \text{J/(kg·°C)}$ | 最大，常用作冷却剂 |
| g 值 | $g = 9.8\ \text{N/kg}$ | 粗略计算取 10 N/kg |
| 安全电压 | 不高于 36 V | 人体安全电压 |
| 家庭电路电压 | 220 V | 中国标准 |
| 人耳听觉范围 | 20 Hz — 20 000 Hz | 超声波、次声波不可闻 |
| 水的冰点/沸点 | 0°C / 100°C | 标准大气压下 |

---

::: tip 使用建议
- 公式要理解**适用条件**，不能生搬硬套
- 同一物理量可能有多个公式，根据已知条件选择最合适的
- 注意**单位换算**，代入数据前统一单位（推荐使用国际单位制）
- 电学中 $P = I^2R$ 和 $P = U^2/R$ 仅适用于**纯电阻电路**（电灯、电热器等），不适用于电动机
:::
