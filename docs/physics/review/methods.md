# 初中物理解题方法

本专题汇总初中物理各类题型的核心解题方法和分析技巧。

## 解题一般步骤

1. **审题**：找出已知量和未知量，标注关键条件（"匀速""漂浮""浸没""正常发光"等）
2. **建模**：画出简图（受力分析图、等效电路图、光路图等）
3. **列式**：根据物理规律列出公式
4. **求解**：统一单位后代入计算
5. **检验**：检查单位、数值合理性（如效率应小于 100%）

## 受力分析

### 步骤

1. 确定研究对象（单个物体或整体）
2. 画重力 $G$：竖直向下，作用在重心，不需要和地球接触，不要遗漏
3. 画弹力：支持力垂直接触面，拉力沿绳方向
4. 画摩擦力：与相对运动（趋势）方向相反
5. 检查其他力：浮力、外加拉力/推力等
6. 验证：每个力都有施力物体，与运动状态吻合

### 常见场景

| 场景 | 受力 | 关系 |
|------|------|------|
| 水平面静止 | $G$、$F_{\text{支}}$ | $F_{\text{支}} = G$ |
| 水平面匀速拉动 | $G$、$F_{\text{支}}$、$F$、$f$ | $F_{\text{支}} = G$，$F = f$ |
| 液体中悬浮 | $G$、$F_{\text{浮}}$ | $F_{\text{浮}} = G$ |
| 液体中被拉着 | $G$、$F_{\text{浮}}$、$F_{\text{拉}}$ | $F_{\text{拉}} + F_{\text{浮}} = G$ |
| 滑轮组（$n$ 段绳） | 向上 $nF$，向下 $G + G_{\text{动}}$ | $F = \dfrac{G + G_{\text{动}}}{n}$ |

### 关键提示词

| 关键词 | 隐含条件 | 解题方向 |
|--------|---------|---------|
| "漂浮"/"悬浮" | $F_{\text{浮}} = G$ | 平衡法 |
| "浸没" | $V_{\text{排}} = V_{\text{物}}$ | 阿基米德原理 |
| "匀速直线" | 受力平衡 | 列平衡方程 |

### 易错点

| 常见错误 | 正确做法 |
|---------|---------|
| 把力的作用效果当成力来分析 | 如"上抛物体受向上的力"——实际只受重力 |
| 认为"物体运动就有动力" | 力是改变运动状态的原因，不是维持原因 |
| 遗漏摩擦力 | 有接触面、有相对运动就有摩擦力 |
| 多加"惯性力" | 惯性是性质，不是力 |

## 浮力计算

### 四种方法速览

| 方法 | 公式 | 适用条件 |
|------|------|---------|
| **称重法** | $F_{\text{浮}} = G - F_{\text{示}}$ | 有弹簧测力计，物体可沉入液体 |
| **压力差法** | $F_{\text{浮}} = F_{\text{向上}} - F_{\text{向下}}$ | 已知上下表面压力 |
| **阿基米德原理** | $F_{\text{浮}} = \rho_{\text{液}} g V_{\text{排}}$ | 已知液体密度和 $V_{\text{排}}$ |
| **平衡法** | $F_{\text{浮}} = G$ | 漂浮或悬浮 |

### 关键注意点

- $V_{\text{排}}$ 是排开液体的体积，**不是**物体的体积。浸没时 $V_{\text{排}} = V_{\text{物}}$，漂浮时 $V_{\text{排}} < V_{\text{物}}$
- 浮力与浸没后的深度无关（液体密度均匀时）
- 浮力只与 $\rho_{\text{液}}$ 和 $V_{\text{排}}$ 有关，与物体密度、形状无关
- $\rho_{\text{物}} < \rho_{\text{液}}$ → 上浮→漂浮；$\rho_{\text{物}} = \rho_{\text{液}}$ → 悬浮；$\rho_{\text{物}} > \rho_{\text{液}}$ → 下沉

## 电路识别

### 三种基本方法

| 方法 | 做法 | 适用场景 |
|------|------|---------|
| **去表法** | 电流表→导线，电压表→断路 | 最常用，快速简化电路 |
| **节点法** | 同一导线连的点标同字母，看各元件两端节点 | 快速判断串并联 |
| **电流路径法** | 从正极出发沿导线走，遇分叉分多条支路 | 复杂电路 |

### 常见误区

| 误区 | 纠正 |
|------|------|
| 电压表有示数就有电流通过电压表 | 电压表电阻极大，几乎没有电流通过 |
| 电流表可以直接接在电源两极 | 电流表内阻很小，直接接电源相当于短路 |
| 并联电路中各支路电压都等于电源电压 | 前提是干路上没有其他元件分压 |
| 开关闭合前滑动变阻器可在任意位置 | 应调到最大阻值（保护电路） |

### 电路故障判断

| 现象 | 可能原因 |
|------|---------|
| 电流表无示数，电压表有示数（≈电源电压） | 电压表所测部分**断路** |
| 电流表有示数，电压表无示数 | 电压表所测部分**短路** |
| 两灯都不亮 | 干路断路 |

## 透镜成像

### 五种情况

| 物距 $u$ | 像距 $v$ | 像的性质 | 应用 |
|---------|---------|---------|------|
| $u > 2f$ | $f < v < 2f$ | 倒立、缩小的**实像** | 照相机 |
| $u = 2f$ | $v = 2f$ | 倒立、等大的**实像** | 测焦距 |
| $f < u < 2f$ | $v > 2f$ | 倒立、放大的**实像** | 投影仪 |
| $u = f$ | 不成像（$v \to \infty$） | 平行光 | 平行光源 |
| $u < f$ | $v > u$（物像同侧） | 正立、放大的**虚像** | 放大镜 |

### 关键规律

- **一倍焦距分虚实**：$u > f$ 实像，$u < f$ 虚像，$u = f$ 不成像
- **二倍焦距分大小**：$u > 2f$ 缩小，$u < 2f$ 放大
- 成实像时：**物近像远像变大，物远像近像变小**
- 实像倒立、异侧；虚像正立、同侧
- 凸透镜被遮住一部分：像**仍然完整**，但亮度变暗

## 效率计算

### 各场景公式对比

| 类型 | $\eta$ 公式 | 有用功 | 总功/总能量 |
|------|------------|--------|------------|
| 滑轮组（竖直） | $\dfrac{G}{nF}$ | $Gh$ | $F \cdot nh$ |
| 滑轮组（水平） | $\dfrac{f}{nF}$ | $f s_{\text{物}}$ | $F \cdot n s_{\text{物}}$ |
| 热机 | $\dfrac{W}{mq}$ | 机械功 | $mq$（燃料放热） |
| 电加热 | $\dfrac{cm\Delta t}{UIt}$ | $cm\Delta t$（水吸热） | $UIt$（电功） |

效率计算的本质：**识别谁是有用的、谁是总的输入。** 先问两个问题——"我的目的是什么？"（有用）"我实际付出了多少？"（总）。

## 图像题

### 解题四步法

1. **看轴**：横轴、纵轴是什么物理量？单位是什么？
2. **看线**：直线（正比→比值恒定）、曲线（关系变化→找特殊点）、水平线（某量不变）
3. **看点**：起点、终点、交点、拐点各有什么物理含义？
4. **多线对比**：同横坐标比纵坐标，或同纵坐标比横坐标

### 常见图像类型

| 图像 | 物理含义 | 关键点 |
|------|---------|--------|
| $s$-$t$ 图 | 位置随时间变化，斜率 = 速度 | 水平线→静止，斜线→匀速 |
| $v$-$t$ 图 | 速度随时间变化，面积 = 路程 | 水平线→匀速，斜线→变速 |
| $m$-$V$ 图 | 质量-体积，斜率 = 密度 | 同种物质过原点直线 |
| 温度-时间（物态变化） | 晶体熔化/液体沸腾 | 水平段对应熔点/沸点 |
| $U$-$I$ 图（定值电阻） | 过原点直线，斜率 = 电阻 | 越陡电阻越大 |
| $U$-$I$ 图（小灯泡） | 曲线（电阻随温度升高而增大） | 求某点电阻用 $R=U/I$ |
| $I$-$R$ 图 | 电压一定时 $I$ 与 $R$ 成反比 | 双曲线一支 |
