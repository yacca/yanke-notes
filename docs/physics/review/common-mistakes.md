# 初中物理易错点专题

本专题总结初中物理中最高频的概念混淆和易错陷阱。

## 一、力学易错点

### 速度相关

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 平均速度是速度的平均值 | 平均速度 $\bar{v} = \dfrac{s_{\text{总}}}{t_{\text{总}}}$，不是各段速度的平均值 |
| s-t 图是物体的运动轨迹 | s-t 图反映位置随时间的关系，不是运动路径 |

### 密度相关

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 密度与质量成正比，与体积成反比 | 密度是物质特性，$\rho = \dfrac{m}{V}$ 是**计算式**不是**决定式** |
| 同种物质，质量减少到一半，密度也减半 | 密度不变（如一块砖切掉一半，密度不变） |

### 重力相关

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| "竖直向下" = "垂直向下" | 竖直向下是沿重力方向（指向地心），垂直向下是垂直于接触面，两者不同 |
| 质量随位置/形状改变 | 质量是物体固有属性，不随位置、形状、状态改变 |

### 力和运动

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 物体受力才会运动 | 力是**改变**物体运动状态的原因，不是维持运动的原因 |
| 速度越大惯性越大 | 惯性只与**质量**有关，与速度无关 |
| 撤去力后物体立即停止 | 撤去力后物体由于惯性继续运动（受阻力会减速直至停止） |
| 平衡力与相互作用力的区分 | 平衡力作用在**同一物体**上；相互作用力作用在**两个物体**上 |

### 压强和浮力

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 压力一定等于重力 | 只有物体放在水平面且不受其他外力时，$F = G$ |
| 液体压强与液体密度和深度之外的因素有关 | 液体压强只与液体密度和深度有关，与容器形状等无关 |
| 物体越重浮力越大 | 浮力只与 $\rho_{\text{液}}$ 和 $V_{\text{排}}$ 有关，与物体重力无关 |
| 沉底的物体不受浮力 | 沉底的物体仍然受浮力（除非与容器底紧密贴合） |
| 只要 $F_{\text{浮}} = G$ 就是悬浮 | 漂浮也有 $F_{\text{浮}} = G$，区别在于漂浮时 $V_{\text{排}} < V_{\text{物}}$ |

### 简单机械

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 省力杠杆也能省功 | 任何机械都不省功，省力则费距离 |
| 机械效率可以大于 100% | 额外功一定存在，$\eta < 100\%$ |
| 功率越大机械效率越高 | 功率表示做功快慢，效率表示有效利用率，两者无关 |

## 二、电学易错点

### 电路识别

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 电压表有示数就有电流通过电压表 | 电压表**电阻极大**，几乎没有电流通过它 |
| 电流表可以直接接在电源两极 | 电流表内阻很小，直接接电源相当于短路，会烧毁电表 |
| 短路就是电流不经过用电器 | 局部短路（一个用电器被短接）仍有电流经过其他用电器 |

### 欧姆定律

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| $R = \dfrac{U}{I}$ 表示电阻与电压成正比 | 电阻是导体本身性质，由材料、长度、横截面积、温度决定，**通常不随 U、I 变化** |
| 滑动变阻器"一上一下"接反 | 都接上面：相当于导线；都接下面：相当于定值电阻 |
| 并联电路中，电阻越并越大 | 并联相当于增大了横截面积，总电阻**越并越小** |

### 电功和电功率

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 灯泡亮暗由额定功率决定 | 灯泡亮暗由**实际功率**决定，$P = UI$ |
| $P = I^2R$ 在任何电路中都适用 | 该公式由 $P = UI$ 和 $U = IR$ 推导而来，$U = IR$ 适用于纯电阻电路 |
| 额定功率随电压变化 | 额定功率是铭牌上标的值，固定不变；实际功率随电压变化 |
| 电功 $W = UIt$ 和电热 $Q = I^2Rt$ 总是相等 | 只有纯电阻电路（电灯、电热器）才有 $W = Q$，电动机 $W > Q$ |

### 安全用电

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 保险丝可以用铜丝代替 | 铜丝熔点高，电流过大时不会熔断，失去保护作用 |
| 家庭电路中各用电器是串联的 | 各用电器**并联**，互不影响 |
| 试电笔的氖管发光说明接触的是零线 | 发光说明接触的是**火线**，氖管两端有 220 V 电压差 |

## 三、热学易错点

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 0°C 的冰变成 0°C 的水不需要持续加热 | 晶体熔化条件：① 达到熔点 ② **继续吸热**。冰在 0°C 时若不吸热不会熔化 |
| 蒸发只能在高温下发生 | 蒸发在任何温度下都能发生 |
| "白气"是水蒸气 | "白气"是水蒸气**液化**形成的**小水珠**（水蒸气是无色透明的） |
| 物体温度越高含有的热量越多 | 热量是过程量，说"吸收/放出热量"，不能"含有"热量 |
| 内能只与温度有关 | 内能与温度、质量、状态、种类都有关 |

## 四、光学易错点

| ❌ 常见错误 | ✅ 正确理解 |
|-----------|-----------|
| 漫反射不遵循反射定律 | 漫反射和镜面反射都遵循反射定律 |
| 平面镜成像"物距变近像变大" | 平面镜成像等大，像的大小不变（只是视角变大） |
| 凸透镜成实像时一定能用光屏承接 | 实像能承接，虚像不能承接（正确的，但题干常反过来设置陷阱） |
| 光从空气斜射入水中时折射角大于入射角 | 光从空气斜射入水，折射角**小于**入射角（空气→其他介质，折射角小） |

## 五、常考易错成语/俗语辨析

| 成语/俗语 | 涉及的物理知识 | 易错点 |
|-----------|--------------|--------|
| "孤掌难鸣" | 力是相互的 | 一个物体无法产生力的作用 |
| "以卵击石" | 力的相互作用 | 鸡蛋和石头受到的力一样大（鸡蛋壳承受力小） |
| "四两拨千斤" | 杠杆原理 | 动力臂远大于阻力臂 |
| "磨刀不误砍柴工" | 压强 $p = F/S$ | 刀磨薄了减小受力面积，增大压强 |
| "坐井观天" | 光的直线传播 | 视野范围随高度变化 |
| "海市蜃楼" | 光的折射 | 不是反射，是折射导致的光线弯曲 |
| "震耳欲聋" | 响度 | 不是音调高，而是振幅大 |

---

> 易错题的根因往往是**概念理解不准确**或**混淆了相近概念**。建议每做错一道题都在旁边记下对应知识点的正确理解。
