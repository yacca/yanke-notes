# 初中物理知识汇总

本页面按板块简洁概述初中物理所有关键知识点。公式部分请参见[公式汇总](../formulas/)。

## 一、力学

### 机械运动
- **长度与时间测量**：刻度尺（零刻度线、分度值、测量范围、估读到分度值下一位）、停表
- **误差与错误**：误差不可避免（可减小），错误可以避免
- **机械运动**：物体位置随时间的变化。运动和静止是相对的，结果取决于参照物
- **速度**：描述运动快慢，$v = \dfrac{s}{t}$。匀速直线运动——速度不变；变速运动——用平均速度描述

### 质量与密度
- **质量**：物体所含物质的多少，不随位置、形状、状态改变。用天平测量
- **天平使用**：放平归零、调平衡、左物右码、镊子取放、调节游码、正确读数
- **密度**：物质特性，$\rho = \dfrac{m}{V}$ 是**计算式**不是**决定式**，密度不随质量和体积变化

### 力
- **力的作用效果**：① 改变物体形状（使物体发生形变） ② 改变物体运动状态（使物体的速度大小或方向发生变化）
- **力的三要素**：大小、方向、作用点
- **力的示意图**：线段长度表示力的大小；线段箭头表示力的方向；线段起点（或终点）表示力的作用点
- **力的作用是相互的**：作用力与反作用力等大、反向、共线、共生
- **弹力**：物体由于发生弹性形变而产生的力，例如：支持力、压力、拉力、弹簧弹力。弹簧测力计——在弹性限度内，伸长量与拉力成正比
- **重力** $G = mg$：由于地球的吸引而使物体受到的力叫做重力，方向竖直向下，作用在重心
- **重心**：形状规则均匀物体的重心在几何中心

### 运动和力
- **牛顿第一定律**（惯性定律）：一切物体总保持匀速直线运动状态或静止状态，除非作用在它上面的力迫使它改变这种状态
- **惯性**：一切物体都有保持原来运动状态不变的性质，**只与质量有关**，与速度无关
- **二力平衡**：同体、等大、反向、共线
- **摩擦力**：两个相互接触的物体，当它们发生相对运动或具有相对运动的趋势时，在接触面上产生一种阻碍相对运动的力
  - 方向与相对运动（趋势）方向相反
  - 静摩擦力——有相对运动趋势但未动
  - 滑动摩擦力——压力越大、接触面越粗糙，摩擦力越大（与速度、接触面积无关）
  - 增大摩擦：增大压力、增大粗糙程度
  - 减小摩擦：减小压力、加润滑油、变滑动为滚动
- **力的合成**：同向相加 $F_{\text{合}}=F_1+F_2$，反向相减 $F_{\text{合}}=|F_1-F_2|$
- **合力为零** → 物体处于平衡状态

### 压强
- **压强**：物体所受压力的大小与受力面积之比叫作压强。$p = \dfrac{F}{S}$，压力是垂直作用在物体表面的力，不一定等于重力
- **液体压强**：$p = \rho gh$，只与液体密度和深度有关，与方向、容器形状无关
- **大气压强**：马德堡半球实验证明存在，托里拆利实验测出大小。标准大气压 $p_0 = 1.013 \times 10^5\ \text{Pa}$
- **流体流速与压强**：流速大的位置压强小（飞机机翼、喷雾器）

### 浮力
- 浮力产生原因：液体对物体上下表面的压力差（$F_{\text{浮}} = F_{\text{向上}} - F_{\text{向下}}$）
- 阿基米德原理：$F_{\text{浮}} = G_{\text{排}} = \rho_{\text{液}} g V_{\text{排}}$
- **浮沉条件**（通过密度比较判断）：
  - $\rho_{\text{物}} < \rho_{\text{液}}$ → 上浮 → 最终漂浮（$F_{\text{浮}} = G$，$V_{\text{排}} < V_{\text{物}}$）
  - $\rho_{\text{物}} = \rho_{\text{液}}$ → 悬浮（$F_{\text{浮}} = G$，$V_{\text{排}} = V_{\text{物}}$）
  - $\rho_{\text{物}} > \rho_{\text{液}}$ → 下沉

### 功和机械能
- **功**：$W = Fs$，力与在力的方向上移动距离的乘积。做功的两个必要因素：**有力、在力的方向上有距离**
- **功率**：$P = \dfrac{W}{t}$，表示做功快慢（不是多少）
- **动能**：与质量和速度有关（质量越大、速度越大，动能越大）
- **重力势能**：与质量和高度有关
- **弹性势能**：与弹性形变程度有关
- **机械能守恒**：只有动能和势能相互转化时，机械能总量不变（忽略摩擦）

### 简单机械
- **杠杆**：$F_1 L_1 = F_2 L_2$。省力杠杆费距离（$L_1 > L_2$），费力杠杆省距离
- **滑轮**：定滑轮不省力能改变方向；动滑轮省一半力不能改变方向
- **滑轮组**：$F = \dfrac{G}{n}$（不计摩擦和动滑轮重）
- **机械效率**：$\eta = \dfrac{W_{\text{有用}}}{W_{\text{总}}} \times 100\%$，**任何机械都不省功**，$\eta < 100\%$
## 二、电学

### 简单电路
- **两种电荷**：正电荷（丝绸摩擦玻璃棒）和负电荷（毛皮摩擦橡胶棒），同性相斥、异性相吸。
- **串联**：电流只有一条路径，各用电器相互影响。$I = I_1 = I_2$，$U = U_1 + U_2$，$R = R_1 + R_2$
- **并联**：电流有多条路径，各用电器互不影响。$I = I_1 + I_2$，$U = U_1 = U_2$，$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$
- **电流表**：串联在电路中，内阻很小，相当于导线
- **电压表**：并联在电路两端，内阻很大，相当于断路
- **短路**：电流不经过用电器直接构成回路（局部短路 vs 电源短路）

### 欧姆定律
- 电阻是导体本身性质，由材料、长度、横截面积和温度决定，**不随 $U$、$I$ 变化**（$R = \dfrac{U}{I}$ 是计算式，不是决定式），同种材料，长度越长电阻越大，横截面积越大电阻越小
- 滑动变阻器：通过改变接入电路的电阻丝长度改变电阻
- $I = \dfrac{U}{R}$：导体中的电流跟两端电压成正比，跟电阻成反比（**同体性、同时性**）
- **串联电阻**：$R = R_1 + R_2$，越串越大
- **并联电阻**：$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$，越并越小

### 电流做功
- **电功**：$W = UIt$，电流做功的实质是电能转化为其他形式能
- **电功率**：$P = \dfrac{W}{t} = UI$，表示电流做功快慢
- **额定功率 vs 实际功率**：额定功率是铭牌标值，固定不变；灯泡亮暗由**实际功率**决定
- **焦耳定律**：$Q = I^2Rt$，适用于任何用电器。纯电阻电路中 $W = Q$，电动机 $W > Q$
- **电能表**：测量用电器消耗电能多少的仪表（单位 kW·h）

### 生活用电
- 家庭电路电压 220 V，各用电器**并联**
- **插座接法**：左零右火上接地；开关接火线
- **测电笔**：手触笔尾金属体，笔尖接触电线，氖管发光为火线
- 保险丝：电阻率大、熔点低（**不可用铜丝代替**）
- **安全电压**：不高于 36 V
- **安全用电**：不接触低压带电体，不靠近高压带电体；避免过载和短路，防止电气火灾

### 电与磁
- **磁现象**：磁极间同名相斥、异名相吸
- **磁感线**：从 N 极出发回到 S 极
- **地磁场**：地磁南极在地理北极附近，地磁北极在地理南极附近
- **奥斯特实验**：通电导体周围存在磁场——电生磁
- **安培定则**：右手握螺线管，四指电流方向，拇指 N 极
- **电磁铁**：螺线管 + 铁芯，电流越大磁性越强，匝数越多磁性越强
- **电磁继电器**：电磁铁控制工作电路通断的开关
- **电动机**：通电线圈在磁场中受力转动，电能 → 机械能，用换向器持续转动
- **电磁感应**：闭合电路切割磁感线产生感应电流——磁生电
- **发电机**：电磁感应原理，机械能 → 电能

### 电磁波
- 电磁波可以在真空中传播，速度 $c = 3.0 \times 10^8\ \text{m/s}$
- 波速 = 波长 × 频率（$c = \lambda f$）
- 电磁波谱（频率从低到高）：无线电波 → 微波 → 红外线 → 可见光 → 紫外线 → X 射线 → $\gamma$ 射线
- 应用：广播通信（无线电波）、遥控（红外线）、灭菌（紫外线）、医学成像（X 射线）

## 三、热学

### 热现象
- **温度**：物体的冷热程度。常用温度计原理——液体热胀冷缩
- **熔化与凝固**：晶体有固定熔点（如冰、铁），非晶体无固定熔点（如蜡、玻璃）
- **汽化与液化**：汽化吸热，液化放热
- **升华与凝华**：升华吸热（干冰、碘），凝华放热（霜、雾凇）
- **晶体熔化条件**：① 达到熔点 ② **继续吸热**。沸腾条件类似：① 达到沸点 ② 继续吸热
- **蒸发与沸腾**：蒸发在任何温度下进行（表面），沸腾在沸点进行（表面+内部）
- **液化方法**：降温、压缩体积

### 内能及其利用
- **分子动理论三要点**：物质由分子构成、分子不停做无规则热运动、分子间有引力和斥力。
- **扩散现象**：不同物质互相接触时彼此进入对方，温度越高扩散越快
- **内能**：物体内部所有分子动能与分子势能的总和。一切物体都有内能
- **改变内能的方式**：做功（能量转化）和热传递（能量转移），两者等效
- **比热容**：反映物质吸热能力的特性，$Q = cm\Delta t$
- **热值**：燃料完全燃烧放热与其质量之比，是燃料本身的特性（$q = \dfrac{Q}{m}$）
- **热机**：将内能转化为机械能的装置。汽油机四冲程（吸气→压缩→做功→排气），做功冲程提供动力
- 能量守恒定律：能量既不会凭空消灭，也不会凭空产生，它只会从一种形式转化为其他形式，或者从一个物体转移到其他物体，而在转化和转移的过程中，能量的总量保持不变。

## 四、光学

### 光现象

- **光的直线传播**：同种均匀介质中沿直线传播（影子、日食月食、小孔成像）
- **光的反射**：反射光线、入射光线、法线在同一平面；反射光线和入射光线分别位于法线两侧；反射角等于入射角（共面、异侧、等角）
- **镜面反射与漫反射**：都遵循反射定律，漫反射使我们能从各个方向看到物体
- **平面镜成像**：等大、等距、正立、虚像。像与物关于镜面对称
- **光的折射规律**：折射、入射、法线三线共面、折射、入射两线分居、空气中角大（光从空气斜射入水中，折射角＜入射角；反之折射角＞入射角）
- **光的色散**：白光由红橙黄绿蓝靛紫七种色光组成
- **色光的三原色**：红、绿、蓝
- **物体的颜色**：反射该色光（白色物体反射所有光，黑色物体吸收所有光）

### 透镜
- **凸透镜**：凸透镜中间厚边缘薄，对光有**会聚**作用。成像规律：$u > 2f$ 倒立缩小实像（照相机）；$f < u < 2f$ 倒立放大实像（投影仪）；$u < f$ 正立放大虚像（放大镜）
- **凹透镜**：凹透镜中间薄边缘厚，对光有**发散**作用，只能成正立缩小的虚像
- **实像与虚像**：实像由实际光线会聚而成，能在光屏上呈现、倒立；虚像由光线的反向延长线相交而成，不能在光屏上呈现、正立
- **三条特殊光线**：平行于主光轴 → 过焦点（或反向延长线过焦点）；过光心 → 方向不变；过焦点 → 平行于主光轴
- **眼睛与眼镜**：近视眼——晶状体曲度过大，用凹透镜矫正；远视眼——晶状体曲度过小，用凸透镜矫正
- **显微镜**：物镜成倒立放大实像（投影仪原理），目镜成正立放大虚像（放大镜原理）
- **望远镜**：物镜成倒立缩小实像（照相机原理），目镜成正立放大虚像（放大镜原理）

## 五、其他

### 声现象
- **声音的产生**：物体振动产生（一切发声体都在振动）
- **声音的传播**：需要介质（固体、液体、气体），**真空不能传声**。15°C 空气中声速 340 m/s
- **回声**：声音遇到障碍物反射回来，听到回声的条件——障碍物距声源至少 17 m
- **三大特征**：
  - 音调：由频率决定（频率越高音调越高）
  - 响度：由振幅决定（振幅越大响度越大），还与距离有关
  - 音色：由发声体本身决定（区分不同发声体的依据）
- 超声波（频率 > 20000 Hz）：超声雷达、B 超、声呐
- 次声波（频率 < 20 Hz）：地震、火山喷发时产生
- **噪声控制三途径**：声源处 → 传播过程中 → 人耳处
- **分贝等级**：保护听力 ≤ 90 dB，工作学习 ≤ 70 dB，休息睡眠 ≤ 50 dB

### 能源与可持续发展
- **能源分类**：
  - 一次能源（直接来自自然界）与二次能源（加工转化）
  - 可再生能源（太阳能、风能、水能）与不可再生能源（化石能源、核能）
- **核能**：核裂变（原子弹、核电站——链式反应可控）和核聚变（氢弹——目前不可控）
- 能量的转化和转移具有**方向性**（不可逆转），所以节约能源十分必要

### 教材改进

任何书籍都可能有瑕疵，下面是我发现的教材中可以改进的地方：

- 人教版八年级上册第96页中的“mirror reflection”应该改成“specular reflection”，它才是和漫反射对应的词。
- 人教版九年级第17页中的“火箭外壳和大气摩擦后温度越来越高”，应该改成“火箭外壳挤压前部空气导致温度越来越高”。
- 人教版九年级第149页中的“magnetic induction line”最好改成“magnetic field lines”。
- 人教版九年级第168页中的“induction current”应该改成“induced current”。
