# 能源与可持续发展

能源是人类社会发展的基石——从钻木取火到核能发电，从化石燃料到太阳能电池，人类利用能源的方式在不断变革。然而，化石能源的日益枯竭和环境问题也向我们提出了严峻挑战。这一章将认识各种各样的能源，了解核能与太阳能的奥秘，并思考如何实现能源的可持续发展。

::: info 能源知识结构
本章将从能源的分类开始，认识化石能源、可再生能源与不可再生能源，学习核裂变与核聚变的原理，了解太阳能的利用方式，并探讨能源消耗对环境的影响以及可持续发展的能源战略。
:::

能源种类繁多，按获取方式可分为一次能源和二次能源，按能否再生可分为可再生能源和不可再生能源。煤、石油、天然气等化石能源是不可再生的，而太阳能、风能、水能等是可再生的。
:::

:::

能量的转化和转移具有方向性，这决定了我们必须节约能源。化石能源的大量使用带来了温室效应、酸雨等环境问题。可持续发展的能源战略要求发展新能源、提高能源利用效率、推广节能技术。
:::

## 能源家族

### 能源的分类

能源可以从不同角度进行分类：

**按获取方式分类：**

| 类别 | 定义 | 举例 |
| :--- | :--- | :--- |
| **一次能源** (primary energy) | 从自然界直接获取的能源 | 煤、石油、天然气、风能、水能、太阳能、核能 |
| **二次能源** (secondary energy) | 由一次能源加工转化而成的能源 | 电能、氢能、汽油、柴油、煤气 |

**一次能源按能否再生分类：**

| 类别 | 定义 | 举例 |
| :--- | :--- | :--- |
| **可再生能源** (renewable energy) | 可以在自然界中源源不断地得到的能源 | 太阳能、风能、水能、地热能、潮汐能、生物质能 |
| **不可再生能源** (non-renewable energy) | 短期内无法从自然界得到补充的能源 | 煤、石油、天然气、核能 |

### 化石能源

**化石能源** (fossil energy) 是指由古代生物的遗骸经过漫长的地质年代形成的能源，主要包括煤、石油和天然气。

| 化石能源 | 形成过程 | 主要用途 | 特点 |
| :--- | :--- | :--- | :--- |
| 煤 (coal) | 古代植物被埋在地下，经复杂变化形成 | 火力发电、供暖、工业燃料 | 储量较丰富，但燃烧污染较大 |
| 石油 (petroleum) | 古代动植物被埋在地下，经复杂变化形成 | 汽油、柴油、化工原料 | 被称为"工业的血液" |
| 天然气 (natural gas) | 与石油类似，主要成分是甲烷 (CH₄) | 民用燃气、发电、化工原料 | 相对清洁的化石能源 |

::: info 化石能源的储量危机
化石能源是不可再生能源，在地球上的储量是有限的。据估计，按照目前的开采速度，石油和天然气可开采的年限约为几十年到一百多年，煤炭约为两百多年。人类正面临着化石能源逐渐枯竭的挑战。
:::

## 核能

### 核能的概念

**核能** (nuclear energy) 是原子核发生变化（裂变或聚变）时释放出的巨大能量。原子核由质子和中子组成，当原子核的结构发生变化时，核子间的结合能就会被释放出来。

核能的释放有两种基本形式：**核裂变**和**核聚变**。

::: info 核能的巨大能量
核能比化学能大得多。1 kg 铀-235 完全裂变释放的能量约等于 2700 吨标准煤完全燃烧释放的能量。这正是核能作为高效能源的重要原因。
:::

### 核裂变

**核裂变** (nuclear fission) 是指重原子核（如铀-235、钚-239）被中子轰击后分裂为两个或多个中等质量原子核的过程，同时释放出巨大的能量和 2~3 个新的中子。

#### 链式反应

核裂变中产生的新的中子又会轰击其他铀核，使裂变反应持续进行下去，形成**链式反应** (chain reaction)。

链式反应有两种控制方式：

| 控制方式 | 特点 | 应用 |
| :--- | :--- | :--- |
| **可控链式反应** | 通过控制中子数量使反应平稳进行 | **核电站**（核反应堆） |
| **不可控链式反应** | 反应在极短时间内剧烈进行，能量瞬间释放 | **原子弹** |

#### 核电站

**核电站** (nuclear power plant) 是利用核能发电的设施，其核心是**核反应堆** (nuclear reactor)。

核电站的能量转化过程：

::: card title="核电站能量转化流程"
核能（核反应堆） → 内能（冷却剂） → 机械能（汽轮机） → 电能（发电机）
:::

具体过程：核反应堆中发生可控的链式裂变反应，释放大量热量；冷却剂（水或液态钠）将热量带出，使水变成高温高压的蒸汽；蒸汽推动汽轮机转动，将内能转化为机械能；汽轮机带动发电机发电，将机械能转化为电能。

::: info 核电站的安全问题
核电站运行中会产生放射性废料，需要妥善处理。历史上发生过切尔诺贝利（1986 年）和福岛（2011 年）等重大核事故，因此核电站的安全性问题一直备受关注。现代核电站建造时有多重安全屏障（燃料包壳、反应堆压力容器、安全壳等），安全性已大幅提升。
:::

### 核聚变

**核聚变** (nuclear fusion) 是指轻原子核（如氘、氚）在超高温条件下结合成较重的原子核（如氦）的过程，同时释放出巨大的能量。

| 核聚变特点 | 说明 |
| :--- | :--- |
| **条件苛刻** | 需要极高的温度（几千万度甚至上亿度）才能使原子核克服库仑斥力 |
| **能量巨大** | 相同质量的核燃料，聚变释放的能量是裂变的 4 倍左右 |
| **燃料丰富** | 氘在海水中储量极其丰富（约 45 万亿吨） |
| **产物清洁** | 聚变产物是氦，没有放射性废料 |
| **尚未可控** | 目前人类尚未实现可控核聚变的商业化应用 |

核聚变的应用：

- **氢弹**：利用原子弹爆炸产生的高温引发氘氚聚变，实现不可控的热核反应，威力远大于原子弹
- **太阳**：太阳内部持续进行着热核聚变反应，每秒钟将约 6 亿吨氢转化为氦，释放出巨大的光和热
- **可控核聚变**（未来展望）：科学家正在研究"人造太阳"（如国际热核聚变实验堆 ITER、中国的 EAST），希望实现可控核聚变，为人类提供近乎取之不尽的清洁能源

::: info 现状
目前人类已经实现了**不可控**的核聚变（氢弹），但尚未实现**可控**的核聚变。可控核聚变一旦实现，将从根本上解决人类的能源问题。
:::

## 太阳能

### 太阳能的来源

**太阳能** (solar energy) 是太阳内部持续发生核聚变反应释放出的巨大能量。太阳内部每时每刻都在进行着氢核聚变成氦核的热核反应，释放出的能量以电磁波（光和热）的形式向外辐射。

太阳是地球上绝大多数能源的**最终来源**：

| 能源 | 与太阳的关系 |
| :--- | :--- |
| 化石能源（煤、石油、天然气） | 古代动植物吸收太阳能后转化储存而来 |
| 风能 | 太阳辐射引起大气温度不均，导致空气流动 |
| 水能 | 太阳辐射使水蒸发，形成降水，水从高处流下 |
| 生物质能 | 植物通过光合作用将太阳能转化为化学能储存 |

### 太阳能的利用方式

人类直接利用太阳能主要有两种方式：

#### 光热转换

**光热转换** (solar thermal conversion) 是利用太阳辐射的热能来加热物体。

| 应用 | 原理 |
| :--- | :--- |
| **太阳能热水器** | 集热器吸收太阳辐射，将水加热 |
| **太阳能灶** | 利用凹面镜或菲涅耳透镜聚焦太阳光，产生高温 |
| **太阳能供暖** | 利用太阳能加热空气或水，实现冬季供暖 |
| **太阳能热发电** | 用大量反射镜聚焦太阳光加热工质，驱动汽轮机发电 |

#### 光电转换

**光电转换** (solar photovoltaic conversion) 是利用太阳能电池（光伏电池）将太阳辐射能直接转化为电能。

- **太阳能电池** (solar cell / photovoltaic cell) 的核心是**半导体材料**（如硅）
- 太阳光照射到半导体上时，产生**光生伏打效应**，将光能转化为电能

::: card title="太阳能电池的应用"
- **太空领域**：人造卫星、空间站的主要能源
- **民用领域**：太阳能路灯、太阳能计算器、太阳能充电器
- **并网发电**：大型太阳能光伏电站、屋顶分布式光伏
- **边远地区**：为电网难以覆盖的地区提供电力
:::

### 太阳能的优缺点

| 优点 | 缺点 |
| :--- | :--- |
| 取之不尽、用之不竭（可再生能源） | 能量分散，能量密度低 |
| 清洁无污染 | 受天气、昼夜、季节影响大 |
| 分布广泛，无需运输 | 能量收集和转换效率较低 |
| 使用安全 | 大型太阳能设备占地面积大 |

## 能源与可持续发展

### 能量转化和转移的方向性

能量的转化和转移具有**方向性** (directionality)：

- **热传递的方向性**：热量只能自发地从高温物体传递到低温物体，不能自发地反向传递
- **机械能与内能转化的方向性**：机械能可以全部转化为内能（如摩擦生热），但内能**不能全部**转化为机械能（热机效率总小于 100%）
- **能量品质的降低**：能量在转化和转移过程中，虽然总量守恒（能量守恒定律），但可利用的能量会逐渐减少，能量的"品质"在降低

::: warning 方向性的启示
能量守恒定律告诉我们能量总量保持不变，但能量的转化和转移具有方向性。这意味着**并非所有能量都能被我们利用**——节约能源是必须坚持的原则。
:::

### 能源消耗对环境的影响

化石能源的大规模使用带来了严重的环境问题：

| 环境问题 | 主要原因 | 主要危害 |
| :--- | :--- | :--- |
| **温室效应** | 大量燃烧化石燃料，排放 CO₂ | 全球变暖、海平面上升、极端气候增多 |
| **酸雨** | 燃烧煤和石油排放 SO₂、NOₓ | 酸化土壤和水体、腐蚀建筑物、破坏森林 |
| **空气污染** | 燃烧化石燃料产生粉尘、有害气体 | 引发呼吸系统疾病、形成雾霾 |
| **水污染** | 石油泄漏、煤矿排水 | 污染水体、危害水生生物 |
| **生态破坏** | 采矿、开采石油破坏地表 | 植被破坏、土地塌陷、生态失衡 |
| **核废料处理** | 核电站产生的放射性废料 | 放射性危害持续数千年，需要安全处置 |

### 可持续发展的能源战略

**可持续发展** (sustainable development) 是指既满足当代人的需求，又不损害后代人满足其需求的能力的发展模式。

在能源领域，可持续发展要求：

::: card title="可持续发展的能源战略"
1. **发展新能源**：大力开发太阳能、风能、水能、核能、生物质能等清洁能源，减少对化石能源的依赖
2. **提高能源利用效率**：通过技术进步减少能源浪费（如节能家电、高效发动机、建筑保温）
3. **推广节能技术**：倡导绿色出行（公共交通、电动车）、节能建筑、垃圾分类与资源回收
4. **优化能源结构**：逐步降低煤炭比例，增加天然气、核能、可再生能源的占比
5. **加强环境保护**：推广清洁燃烧技术、碳捕集与封存（CCS）、发展循环经济
:::

::: info 我国的能源政策
我国明确提出"碳达峰"（2030 年前）和"碳中和"（2060 年前）的目标。这要求我国加快能源结构调整，大力发展非化石能源，构建清洁低碳、安全高效的现代能源体系。
:::

#### 未来能源展望

随着科技进步，人类正在探索多种新型清洁能源技术：

| 技术方向 | 前景 |
| :--- | :--- |
| **可控核聚变** | 一旦实现，将提供近乎无限的清洁能源 |
| **高效太阳能电池** | 钙钛矿太阳能电池等新技术有望大幅提高光电转换效率 |
| **氢能** | 氢是清洁的能源载体，燃料电池技术正在快速发展 |
| **储能技术** | 大规模储能（如锂电池、抽水蓄能）是解决可再生能源间歇性的关键 |
