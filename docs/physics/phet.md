# PhET 仿真实验

## 力学

- [密度](/physics/mass-and-density/phet-density) — 通过质量与体积的测量，理解密度的概念
- [质量和弹簧](/physics/mass-and-density/phet-density) — 探究弹簧的伸长量与所挂物体质量的关系
- [力和运动](/physics/force/phet-forces-and-motion) — 探究力与运动状态变化的关系
- [浮力](/physics/buoyancy/phet-buoyancy) — 探究浮力大小与排开液体体积的关系
- [能量滑板公园](/physics/work-and-energy/phet-energy) — 观察动能与势能的相互转化
- [平衡探究实验](/physics/simple-machines/phet-balancing-act) — 探究杠杆平衡条件

## 电学

- [气球和静电](/physics/simple-circuits/phet-balloons-static) — 体验静电感应与电荷相互作用
- [静电电压](/physics/simple-circuits/phet-john-travoltage) — 通过人体摩擦起电观察静电电压
- [电路组件实验：直流](/physics/simple-circuits/phet-circuit-kit) — 搭建直流电路，测量电流与电压
- [电线的电阻](/physics/ohms-law/phet-resistance-in-a-wire) — 探究导体电阻与长度、横截面积的关系

- [磁铁与电磁铁](/physics/electricity-and-magnetism/phet-magnets-and-electromagnets) — 探究磁铁的磁场与电磁铁的特性
- [发电机](/physics/electricity-and-magnetism/phet-generator) — 观察电磁感应现象与发电原理
