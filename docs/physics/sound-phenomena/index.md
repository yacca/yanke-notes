# 声现象

声音是我们感知世界的重要方式。清晨的鸟鸣、课堂上的朗读声、远处传来的汽笛声……声音的世界丰富多彩。声音是如何产生的？又是如何传播到我们耳朵里的？不同声音为什么听起来不一样？

::: info 声学知识结构
本章将从声音的产生和传播开始，学习声音的三个特性，了解声在现代科技中的广泛应用，并认识噪声的危害及控制方法。
:::

## 声音的产生和传播

### 声音的产生

声音是由物体的**振动** (vibration) 产生的。振动停止，发声也停止。

**声源** (sound source) 是指**正在发声的物体**。

| 发声体 | 振动部位 |
| :--- | :--- |
| 人（声带） | 声带的振动 |
| 小提琴 / 二胡 | 琴弦的振动 |
| 笛子 | 空气柱的振动 |
| 鼓 | 鼓面的振动 |
| 蝉 | 腹部鼓膜的振动 |
| 蜜蜂 / 蚊子 | 翅膀的振动 |

::: warning 注意
正在发声的物体一定在振动，但振动的物体不一定都能被人耳听到（如次声波、超声波）。
:::

### 声音的传播

声音的传播需要**介质** (medium)。介质可以是固体、液体或气体。**真空不能传声**。

- **固体传声**：隔壁房间的敲击声通过墙壁（固体）传播
- **液体传声**：在水中可以听到岸上的声音；钓鱼时脚步声会把鱼吓跑
- **气体传声**：我们平时听到的声音主要通过空气传播

> 声音以**声波** (sound wave) 的形式向四面八方传播。声波是一种机械波，类似于水面的波纹——声源振动引起周围介质的振动，这种振动由近及远地传播出去，就形成了声波。

### 声速

声音在介质中的传播速度叫作**声速** (speed of sound)。声速的大小与介质的**种类**和**温度**有关。

- 一般情况下，**固体中声速 > 液体中声速 > 气体中声速**
- 在同种介质中，**温度越高，声速越大**

| 介质（15℃） | 声速 |
| :--- | :--- |
| 空气（15℃） | 340 m/s |
| 水 | 约 1500 m/s |
| 钢铁 | 约 5200 m/s |

### 回声

声音在传播过程中遇到障碍物会被反射回来，人们把反射回来的声音叫作**回声** (echo)。

**区分回声与原声的条件：** 回声到达人耳比原声晚 **0.1s** 以上，人耳才能将回声与原声区分开。这就要求障碍物到人的距离至少为 **17 m**（空气中声速按 340 m/s 计算）。

$$s = \frac{1}{2} \times 340 \text{m/s} \times 0.1\text{s} = 17\text{m}$$

::: card title="回声的应用"
- **回声测距**：利用回声可以测量距离（如声呐探测海底深度）
- **回声加强原声**：当障碍物距离小于 17 m 时，回声与原声混在一起，使原声**加强**（如音乐厅的混响设计）
:::

## 声音的特性

### 音调

**音调** (pitch) 是指声音的**高低**。音调由发声体振动的**频率** (frequency) 决定。

- **频率**：物体每秒振动的次数，单位是**赫兹** (Hz)
- 频率越高，音调**越高**（声音尖锐）
- 频率越低，音调**越低**（声音低沉）

| 发声体 | 频率范围 | 音调特点 |
| :--- | :--- | :--- |
| 蚊子的翅膀 | 约 300-600 Hz | 音调高（嗡嗡声尖锐） |
| 人的声带（女声） | 约 200-300 Hz | 音调较高 |
| 人的声带（男声） | 约 80-200 Hz | 音调较低 |
| 大鼓 | 较低频率 | 音调低（声音浑厚） |

::: info 超声波与次声波
人耳能感知的频率范围大约是 **20 Hz ~ 20000 Hz**。

- **次声波** (infrasound)：频率低于 20 Hz 的声波——地震、火山爆发、核爆炸等都会产生次声波
- **超声波** (ultrasound)：频率高于 20000 Hz 的声波——蝙蝠、海豚能发出和接收超声波，用于导航和捕食

:::

### 响度

**响度** (loudness) 是指声音的**强弱**。响度由发声体振动的**振幅**决定。

- **振幅** (amplitude)：物体振动的幅度（即振动时偏离平衡位置的最大距离）
- 振幅越大，响度**越大**
- 响度还跟距离发声体的**远近**有关——距发声体越远，听到的声音越小

**声音的波形：**

- 响度大 ↔ 波形**振幅大**（波峰高）
- 响度小 ↔ 波形**振幅小**（波峰低）

> 生活中减小声音响度的常用方法：轻拿轻放、轻声细语、在声源处加隔音罩等。

### 音色

**音色** (timbre) 是声音的**品质**和**特色**。音色由发声体本身的**材料**和**结构**决定。

- 不同的发声体由于材料、结构不同，发出的声音音色不同
- **音色是区分不同发声体的重要依据**——即使音调和响度相同，我们也能通过音色分辨出不同乐器或不同人的声音

::: warning 音色辨析
- "闻其声而知其人"——通过音色判断说话人是谁
- 不同乐器演奏同一首乐曲（音调、响度相同），听起来不同——因为音色不同
- 利用音色可以鉴别机器运转是否正常——机器故障时发出的噪声音色会发生变化
:::

### 乐音与噪声

| | 乐音 (musical sound) | 噪声 (noise) |
| :--- | :--- | :--- |
| **物理学角度** | 声源做**有规则**的振动，波形**有规律** | 声源做**无规则**的振动，波形**杂乱无章** |
| **环保角度** | 凡是人们**愿意听**的声音 | 凡是妨碍人们正常休息、学习和工作的声音 |
| **举例** | 音乐、歌声 | 机器轰鸣声、汽车喇叭声、装修电钻声 |

## 声的利用

### 声传递信息

声波可以传递信息，在生活和科技中有广泛应用：

| 应用 | 原理 | 举例 |
| :--- | :--- | :--- |
| **回声定位** | 发出超声波，根据回声判断障碍物的位置和距离 | 蝙蝠、声呐 (SONAR) |
| **B 超** | 向人体内发射超声波，接收反射回来的声波形成图像 | 医学诊断中的 B 超检查 |
| **声呐探测** | 利用声波在水中的传播和反射进行探测和定位 | 探测海底深度、鱼群定位 |
| **金属探伤** | 超声波在金属中传播时遇到裂纹会产生异常反射 | 检测金属构件内部缺陷 |

> 声呐（SONAR，Sound Navigation and Ranging）利用超声波在水中传播距离远的特点进行探测。先向水中发出超声波，测出从发出到接收到回声的时间 $t$，再利用 $s = \frac{1}{2}vt$ 计算距离。

### 声传递能量

声波也可以传递能量。超声波由于频率高、能量集中，在工业、医疗等领域有重要应用：

| 应用 | 原理 |
| :--- | :--- |
| **超声波碎石** | 利用超声波的高能量将体内的结石击碎 |
| **超声波清洗** | 利用超声波在水中产生的高频振动清洗精密仪器 |
| **超声波焊接** | 利用超声波使塑料或金属接触面摩擦生热而熔接在一起 |
| **超声波雾化** | 利用超声波将药液打散成微小雾滴（如医用雾化器） |

::: info 声传递能量的实验
在扬声器前放一支点燃的蜡烛，当播放音乐时，烛焰会随着音乐**晃动**——这说明声波可以传递能量。扬声器发出的声波使空气振动，空气的振动带动烛焰晃动。
:::

## 噪声的危害和控制

### 噪声的来源

噪声的主要来源包括：

1. **交通噪声**：汽车、火车、飞机等交通工具发出的声音
2. **工业噪声**：工厂机器的运转声，建筑工地的施工声
3. **生活噪声**：大声喧哗、音响声、家电声等

### 噪声的等级

声音的强弱通常用**分贝** (decibel, dB) 来表示。分贝数越大，表示声音越强。

| 分贝 (dB) | 声音 | 感受 |
| :--- | :--- | :--- |
| 0 dB | 人刚能听到的最弱声音 | 听觉下限 |
| 10-20 dB | 轻声耳语、树叶沙沙声 | 非常安静 |
| 30-40 dB | 图书馆、卧室 | 安静 |
| 50-60 dB | 正常交谈 | 较安静 |
| 70-80 dB | 繁华街道、大声说话 | 较吵 |
| 90-100 dB | 电锯声、汽车喇叭 | 很吵，长期暴露会损伤听力 |
| 120 dB | 喷气式飞机起飞 | 震耳欲聋，人耳会感到疼痛 |

> **为了保护听力：** 声音不能超过 90 dB。<br>
> **为了保证工作和学习：** 声音不能超过 70 dB。<br>
> **为了保证休息和睡眠：** 声音不能超过 50 dB。

### 噪声的控制

控制噪声可以从以下三个途径着手：

| 控制途径 | 方法 | 举例 |
| :--- | :--- | :--- |
| **在声源处控制** | 防止噪声产生 | 安装消声器、加隔音罩、禁止鸣笛 |
| **在传播过程中控制** | 阻断噪声传播 | 植树造"隔音林"、安装隔音板、关闭门窗 |
| **在人耳处控制** | 防止噪声进入耳朵 | 佩戴耳塞、耳罩、头盔 |

> 其中，**在声源处控制噪声**是最有效、最根本的措施。
